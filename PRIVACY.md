# Privacy Policy — Free Local AI Setup Script

Plain English. No legal jargon.

---

## What the script does

This script installs AI software on your laptop. That's it.

## What data we collect

**None.**

The script does not:
- Ask for your name, email, or any personal information
- Create an account
- Connect to GotLaptopParts.com servers at any point during execution
- Send usage statistics anywhere
- Install analytics, tracking, or telemetry of any kind
- Report what model you installed or whether setup succeeded

## What happens when you run the script

1. Your laptop connects to **Homebrew** (Mac) or **winget** (Windows) — standard package managers
2. Software is downloaded from each tool's official servers (Ollama.com, LMStudio.ai, Jan.ai, AnythingLLM.com)
3. An AI model is downloaded from **Ollama.com**
4. Files are created on your Desktop (welcome guide, shortcut, verification report)
5. A browser tab opens for the Page Assist extension (optional — you choose to install it)

GotLaptopParts.com is not involved in any of these connections.

## Your AI conversations

Once installed, your AI runs entirely on your laptop's hardware.

- Your prompts never leave your device
- Your documents never leave your device
- Your conversation history is stored locally only
- No company — including GotLaptopParts — can see what you discuss

This is the entire point of local AI.

## Verification

This script is open source. Every line is in this repository. You can read it before running it:

```bash
# Mac
curl -s https://gotlaptopparts.com/ai-setup/mac.sh > setup.sh
cat setup.sh   # read it
bash setup.sh  # then run it
```
